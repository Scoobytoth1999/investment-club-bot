Learn about investing and research smart - I'm here to help you understand, not tell you what to buy!

🔑 Setup Required

To use this bot, you need an Anthropic API key. Your teacher can set this up:

  1. Go to console.anthropic.com
  2. Create an account (or sign in)
  3. Go to "API Keys" and create a new key
  4. Paste the key below

The key is stored only in your browser and never sent anywhere except to Anthropic's API.
